    About

    I'm Ryan Knight. I work as a race engineer in endurance racing in the WRL, and Knight's Garage started because I kept building setups for myself that were faster than anything I could find online — so I started sharing them.

    Everything here is built the same way I'd approach a real car: test it, measure it, adjust it, and only hand it off once it's actually fast. The lap time videos aren't marketing — they're the same proof I'd want to see before trusting a setup myself.

    Knight's Garage — built by an engineer, not a marketing team.
